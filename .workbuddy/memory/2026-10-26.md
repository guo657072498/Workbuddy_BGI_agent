# 2026-10-26 工作日志

## udi-xml-tool：UDI XML 转 Excel 工具

- 解析两类 XML：终端接口（出入库单，DocHeader+HasProducts+Data）与关联关系（生产入库单，Relation+Batch+Code）
- 生产入库单的码按「先箱码、后跟盒码」排列，盒码 parentCode 指向当前箱码。**按 XML 顺序切块，不靠流水号推箱内成员**（实测箱1 流水 209~285、箱2 282~358 有重叠跳号）
- 30 位 UDI 码强制文本格式，写盘后回读校验，防科学计数法精度丢失
- 交付形态：免安装单文件 exe（14MB，tkinter GUI，支持拖拽 + zip 批量）
- 环境：Python 3.14（D 盘，带 tkinter），PyInstaller 6.22.3

### 踩过的坑

1. `udi_parser/__init__.py` 是空文件 → PyInstaller 当成命名空间包，漏收子模块，exe 启动报 `No module named 'udi_parser.source'`。修复：`__init__.py` 里显式 import 所有子模块
2. PyInstaller 6.x 的 spec 中 `datas` 必须是 3 元组，`collect_data_files` 的返回方式不兼容
3. 日志回调抛异常会中断整批转换（GBK 控制台编码不了 ✓ 字符）→ `converter._log` 加 try/except
4. `.gitignore` 里 `dist/` 匹配任意层级，把要交付的 exe 也忽略了 → 改为 `/dist/`
