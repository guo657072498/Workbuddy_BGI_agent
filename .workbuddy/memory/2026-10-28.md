### 需求落点

### 主数据设计（关键决策）
- 存储：`exe同目录\主数据\产品主数据.xlsx` / `法人主数据.xlsx`，xlsx 便于用户直接用 Excel 看。
- 种子：随 exe 打包脱敏假数据，首启落盘；**已有数据绝不覆盖**；新版种子有新增条目时弹窗询问合并。
- 真实模板格式（用户提供）：
  - 产品：`最小销售单元产品标识（UDI） / 大箱标识 / SAP编码 / 产品名称/通用名称 / 规格型号 / 特殊储存或操作条件 / 分类` —— **7 列全存**
  - 法人：`法人编码 / 法人名称`
- 表头匹配：全角→半角、去空格归一；换模板只改 `masterdata/importing.py` 的 `COLUMN_ALIASES`。
- 输出只用到 `prod_name`、`spec`；其余列留存备用，加列只需改 `BILL_COLUMNS`。

### 踩过的坑（重要，写进 README 了）
1. **`Analysis(datas=...)` 是 2 元组 `(源文件, 目标目录)`**，目标目录要带斜杠；
   `a.datas.append(...)` 才是 3 元组。写错的表现是「exe 能跑但主数据 0 条」，很难查。
2. **`打包exe.bat` 原来删整个 `dist`**，会把用户跑出来的 `dist\输出结果` 一起删。已改为只删 exe。
3. **exe 是 `console=False`**，自检输出看不到，已改为写 `<输出目录>\_selftest.log`。
4. **`openpyxl` 必须打进包**——零依赖通道只能写 xlsx 不能读。
5. 自检在「没有任何输入」时曾误报通过，已加 `if not sources: return 1`。
