# 办公助理工作区

这是我的办公助理工作区。我在这里让 AI 助理「办公助理」帮我做日常办公自动化与代码小工具，
每个任务一个文件夹，过程和成品都留在这里可追溯。

> 状态取值：`进行中` / `已完成` / `已归档` / `暂停` / `废弃`

## 怎么用这个工作区

**给我派任务**：把文件（或一个文件夹）丢给我，说明要做什么，我会建一个任务文件夹。

**说「归档」**：我会按 `docs/ARCHIVE.md` 逐条检查规范（敏感信息、大文件、目录结构、索引是否更新），
检查通过后提交并推送到 GitHub。

**改成果**：告诉我哪里要改，我改完更新任务 README 和上方索引。

## 目录说明

| 路径 | 说明 |
|---|---|
| `tasks/` | 所有任务，一个任务一个文件夹，命名 `YYYYMMDD-英文短名` |
| `tasks/_template/` | 新任务 README 骨架模板 |
| `docs/ARCHIVE.md` | 归档检查清单（我的执行手册） |
| `AGENTS.md` | 我的身份与行为规则 |
| `.workbuddy/memory/` | 工作日志，按日期记录每天做了什么 |

## 任务命名规则

```
tasks/20261026-udi-xml-tool/
        └─┬────┘ └────┬────┘
       创建日期     英文短名
```

- 日期是**任务创建日**，一旦确定不再修改
- 名称用全小写英文 + 连字符（中文路径在 GitHub 上会变成乱码）
- 按名称排序 = 按时间排序

## Git 约定

- 主分支：`main`
- 远程仓库：https://github.com/guo657072498/Workbuddy_BGI_agent

提交、推送这些操作都由我来做，不用记命令。
详细规范见 `AGENTS.md`（行为规则）和 `docs/ARCHIVE.md`（归档流程）。

## 敏感信息

仓库为私有，但仍严禁提交：

- `.env` / `.env.*`、`*.pem`、`*.key`
- `secrets.json`、`credentials.json`、`token.json`
- 任何第三方平台的访问令牌
- **含真实客户 / 患者 / 员工个人信息的样例数据**（需脱敏后入库）

相关规则已写入 `.gitignore`，归档时会强制扫描。
