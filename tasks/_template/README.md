## 目录结构

**代码类**

```
YYYYMMDD-<英文短名>/
├── README.md          本文件
├── src/               源码
├── dist/              当前版本交付物（入库）
├── releases/          历史版本及当前版本归档（入库）
├── VERSIONS.md        版本台账（工具/技能/持续迭代成果必需）
├── samples/           脱敏样例输入（入库，≤5MB）
└── _out/              运行产物（不入库，可随时删）
```

**文档类**

```
YYYYMMDD-<英文短名>/
├── README.md          本文件
├── deliverables/      最终 Excel/Word/PDF（入库）
├── samples/           参考输入、模板（入库）
└── _out/              中间稿、试算表（不入库，可随时删）
```

> 交付物叫 `output` 之类也没关系，放 `deliverables/` 下就不会被忽略；
> 但放进 `tasks/<任务>/output/` 会被 `.gitignore` 静默丢弃。
> 一次性分析或文档首次交付可不建 `VERSIONS.md` 和 `releases/`；首次修订时再补齐。
